# Plan: считать статистику в академических часах (2 акад. ч. на пару)   (slug: academic-hours-stats)

## TL;DR
Сейчас analytics считает длительность пары по реальному звонковому времени (95 мин ≈ 1.58 астр. ч).
Нужно считать каждую пару как **2 академических часа**. Все агрегаты часов проходят через один
хелпер `lesson_hours()` в `domain/analytics.py`, поэтому фикс — одна константа + правка ярлыков в отчёте
и одного теста. НЕ трогаем звонковое время там, где оно реально нужно: события Google Calendar,
детекция ранних/поздних пар, и «окна» между парами остаются в астрономических часах.

## Acceptance criteria
- `lesson_hours(lesson)` возвращает `2.0` для любого валидного слота (без зависимости от длительности слота).
- Все агрегаты часов кратны 2.0 на пару: `total_hours` и `by_type` (workload), часы/доли по дисциплинам,
  часы/доли по преподавателям, часы по аудиториям/корпусам (geography), средние по неделям и по чётности (dynamics).
- Инвариант: `compute_workload(...).total_hours == 2.0 * total_lessons`.
- В `report.html` ярлыки часов, производных от пар, показывают академические часы («акад. ч.»), а не «ч».
- Плитка «Часов в окнах» остаётся в астрономических часах и **явно** помечена другим ярлыком
  (напр. «астр. ч»), чтобы два разных смысла не делили один ярлык «ч».
- `make test` и `make lint` проходят.

## Blockers
Нет. Skeptic verdict: **proceed**. Обе HIGH-находки (устаревший тест; хирургичность правки — не трогать
`slot_to_times`/`bell_schedule`/`event_factory`) уже учтены в плане. MED (смешение единиц под ярлыком «ч»)
разрешена: плитка окон получает отдельный ярлык «астр. ч». LOW (magic number) разрешена именованной константой.

## Out of scope
- Изменение логики «окон» и ранних/поздних пар на академические часы (остаются астрономическими).
- `domain/bell_schedule.py` (звонковое время всё ещё нужно для окон/ранних-поздних — не меняем).
- Google Calendar sync / `event_factory` (длительность события = реальное звонковое время).
- Конфиг-опция для «академического часа» (жёсткая константа в стиле `bell_schedule`).
- Таблица слотов «пара→кол-во часов» (все 8 слотов одинаковы, `time_slot` — один int; плоская константа корректна).

## Assumptions
- Нет `.memory-bank/`; план построен на чтении исходников.
- Все слоты — одинаковые двухчасовые пары (нет коротких/сдвоенных); API не возвращает длительность,
  плоская константа 2.0 однозначна.
- Ярлык рендерится как «акад. ч.» (сокращение). При желании легко заменить на «акад. часов».
- Побочный эффект (by design): `share_pct` по дисциплинам/преподавателям теперь равен доле по числу пар
  (часы пропорциональны числу пар). Отметить в commit/PR, чтобы не приняли за баг.
